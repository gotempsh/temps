Adversarial audit of the v1 components and console screens. Two sources: a
code read of every `op/*` primitive and every `ConsoleV1*` screen against the
stated rules, and browser probes on `/v1` at 1440 and 390 (target sizes,
focus management, keyboard reach, truncation, hidden-below-md controls,
sort indicators, filter states). Items marked **[verified]** were reproduced
in the browser; the rest are from the code read with line references.

## Systemic patterns

1. **Keyboard affordances are drawn, not wired.** Kbd badges without
   handlers in five files; where handlers exist they hang on `window` with a
   tagName guard, so promise and behaviour drift both ways.
2. **Chrome asserts state the data layer never applies.** Range pickers,
   chart selection and paged sort all render confident copy over transforms
   that are inert or page-local.
3. **Below md the console loses function, not layout.** Row actions, the
   hint row, live/pause, the workspace Picker and the selection notice all
   go away with `hidden md:*`, with no phone substitute.
4. **Confirmation is inverted.** Typed confirms guard reversible edits; a
   production deploy, a matrix toggle, stopping outbound mail and a
   checkpoint restore go through on one click.
5. **The docs' most specific rules are the ones broken.** Tabs on a record,
   a fact said twice, colour without a state word, hues outside the palette,
   non-interactive text as links.

## What passed

- No horizontal overflow on any screen at 390 or 1440.
- Typing in a filter does not trigger `/`, `j`, `k` or digit shortcuts.
- Picker returns focus to its trigger on Escape.
- Contrast: all text passes AA in both modes after the token change (see
  brand §4), the only exception being `aria-hidden` rule-soft separators.
