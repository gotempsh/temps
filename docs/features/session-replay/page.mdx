# Session Replay

Watch recordings of real user sessions to reproduce bugs, understand drop-off points, and validate UX changes — all stored on your own server. {{ className: 'lead' }}

---

## Overview {{ anchor: true, id: 'overview' }}

Session replay captures DOM snapshots and mutations, user interactions, console output, and network activity. Unlike third-party services, Temps session replay is fully self-hosted: recordings never leave your infrastructure.

<Row>
  <Col>
    **What is recorded**
    - DOM mutations and CSS changes
    - Clicks, scrolls, and keyboard events
    - Navigation and page transitions
    - Console log output
    - Network requests (optional)
    - JavaScript errors
  </Col>
  <Col>
    **Platform properties**
    - Complete data ownership — no third-party uploads
    - GDPR-compliant with configurable redaction
    - Unlimited recordings (storage is on your server)
    - Error correlation — link sessions to error events
    - Configurable sampling rate to control volume
  </Col>
</Row>

---

## Features {{ anchor: true, id: 'features' }}

<Properties>
  <Property name="DOM Recording">
    Captures DOM snapshots and mutations, CSS styles, and input events (with privacy controls applied before capture)
  </Property>
  <Property name="Event Timeline">
    Visual timeline of all interactions — clicks, scrolls, navigation, and errors
  </Property>
  <Property name="Console Logs">
    Browser console output captured during the session and shown alongside the recording
  </Property>
  <Property name="Network Activity">
    API requests and responses recorded optionally — disable per-domain if needed
  </Property>
  <Property name="Performance Metrics">
    FPS, memory usage, and page load times overlaid on the timeline
  </Property>
  <Property name="Error Correlation">
    Sessions linked to error events so you can jump directly to the recording where an error occurred
  </Property>
</Properties>

## Privacy controls {{ anchor: true, id: 'privacy-controls' }}

Session replay applies redaction before data leaves the browser — sensitive content is never transmitted.

<Row>
  <Col>
    **Automatic redaction**
    - Password inputs — always masked
    - Credit card fields — always masked
    - Email and phone — configurable
    - Custom CSS selectors via `blockClass` and `maskTextSelector`
  </Col>
  <Col>
    **Consent and sampling**
    - Opt-in mode — recording starts only after user consent
    - Opt-out mode — user can disable recording
    - Geo-based rules for GDPR regions
    - `sessionSampleRate` to record a fraction of sessions
  </Col>
</Row>

## Setup {{ anchor: true, id: 'setup' }}

<CodeGroup title="Configure Session Replay">
```typescript {{ title: 'React' }}
import { TempsAnalyticsProvider } from '@temps-sdk/react-analytics';

function App() {
  return (
    <TempsAnalyticsProvider
      enableSessionRecording={true}
      sessionRecordingConfig={{
        sessionSampleRate: 0.1,        // record 10% of sessions
        maskAllInputs: false,
        blockClass: 'sensitive-data',  // add this class to hide elements
        maskTextSelector: 'input[type="password"], input[type="email"]',
      }}
    >
      <YourApp />
    </TempsAnalyticsProvider>
  );
}
```

```javascript {{ title: 'Vanilla JS' }}
temps.init({
  projectId: 'my-app',
  sessionReplay: {
    enabled: true,
    sampling: 0.1,
    privacy: {
      maskAllInputs: false,
      blockClass: 'no-record',   // elements with this class are blocked
      maskClass: 'mask-content', // elements with this class are masked
    },
  },
});
```
</CodeGroup>

## Replay player {{ anchor: true, id: 'replay-player' }}

The replay player in the Temps dashboard provides a full-featured interface for watching recordings.

**Player controls:**
- Play, pause, and variable-speed playback
- Timeline scrubber with event markers (clicks, navigation, errors)
- Console panel showing log output at each timestamp
- Network panel showing requests and responses
- Device viewport emulation to match the user's screen size

<Note>
  Session recordings are compressed before storage. A typical five-minute session uses approximately 500 KB.
</Note>
