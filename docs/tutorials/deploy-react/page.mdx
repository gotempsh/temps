# Deploy React on Your Own Server

**Deploy your React app and Temps serves it as static files** — running your build, serving the `dist/` or `build/` output from the Temps proxy with no container running, and routing all paths through `index.html` for client-side navigation. {{ className: 'lead' }}

---

## Quickstart {{ anchor: true, id: 'quickstart' }}

From your project root, deploy with your preferred package manager:

<CliCommands commands={[
  { args: "up" },
]} />

Temps detects a Vite app from its `vite.config.js` or `vite.config.ts` and uses the **Vite** preset. Create React App projects aren't detected from the repository, so choose the **React App** preset (`react-app`), with `up --preset react-app` or under **Project → Settings → Build & deploy → Build → Framework**.

Both presets install dependencies with the package manager your lockfile points to, so commit your lockfile (for example `package-lock.json`). They then run its `build` script (for example `npm run build`) and serve the output. Your app is live with HTTPS in a few minutes.

---

## What Temps handles automatically {{ anchor: true, id: 'what-temps-handles-automatically' }}

| Feature | How Temps handles it |
| ------- | -------------------- |
| Build | Your package manager's `build` script |
| Output | Serves `dist/` (Vite, or the `build.output_dir` set in `.temps.yaml`) or `build/` (Create React App) |
| HTTPS | Let's Encrypt certificate, auto-renewed |
| Client-side routing | 404 → index.html fallback configured automatically |
| Cache headers | Hashed assets get long-lived cache headers |
| Preview deployments | Opt-in; once enabled, each branch gets its own preview environment |

## Environment variables {{ anchor: true, id: 'environment-variables' }}

Vite environment variables (prefixed `VITE_`) are embedded at build time:

<CliCommands commands={[
  { args: "environments vars set VITE_API_URL \"https://api.example.com\" -e production" },
]} />

These values are baked into the bundle when it's built. Changing a variable doesn't redeploy the app; deploy again for the new value to take effect. Create React App works the same way with `REACT_APP_` variables.

---

## Backend API {{ anchor: true, id: 'backend-api' }}

If your React app calls a backend API, deploy your backend as a separate Temps project and set `VITE_API_URL` to its URL. For full-stack apps in a monorepo, set the **Root directory** in project settings for each app — see [Deploy a Project](/docs/your-first-deployment).
